About Enterprise Copilot

Phase 0 · v1 — what this workspace is and how it's built.

Mission

Build and maintain a minimal, reliable Enterprise Copilot — a chat assistant backed by agents, skills, retrieval over your own documents, and guardrails, with human-in-the-loop approval on risky actions like code execution.

Architecture

  • FastAPI + Pydantic backend, this page as a plain HTML/CSS/JS/Bootstrap SPA frontend.
  • Agents run through a single AgentOrchestrator contract (currently backed by AutoGen) — application code never depends on the agent framework directly.
  • Guardrails check every chat request's input and output, visibly, before and after the model runs — a Phase 0 feature, not a placeholder.
  • Knowledge/RAG documents and generation skills support the full add / list / view / update / delete lifecycle, all through POST APIs.

Scope

v1 keeps infrastructure in-memory or file-backed locally rather than a real database or production sandbox — local code execution is development-only. This About page and the Login page are static; there is no account system behind either yet.
