# Dependencies for hosted_tools_server.py ONLY — deliberately its own
# requirements file, separate from the repo root's requirements.txt. This
# server is meant to deploy as its own standalone Render service with no
# dependency on the Enterprise Copilot app package (app/) at all — it never
# imports anything from app/, and the main app never imports anything from
# mcp_servers/ either (see hosted_tools_server.py's module docstring). A
# Render "Root Directory" of mcp_servers/ pointed at this file installs only
# what this one small server needs, not the full app's much heavier stack
# (autogen, sqlalchemy, boto3, ...).
#
# mcp<2 is REQUIRED, not a style preference: mcp 2.x renamed FastMCP to
# MCPServer and changed its API (see the deploy failure this pin fixes —
# ModuleNotFoundError: No module named 'mcp.server.fastmcp' — a bare
# unpinned "mcp" here installed 2.x on a fresh Render build while local dev
# venvs stayed on whatever was already installed, silently drifting). Kept
# in sync with the main app's own requirements.txt pin.
mcp>=1.11.0,<2
httpx
uvicorn
